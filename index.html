Module de création

Trace une zone libre d’au moins 4 × 4 cases. L’entrée est une ouverture dans le mur. Le relief est aplani au niveau du premier coin si l’option est cochée.

Glisse pour dessiner le chemin, puis relâche. Le relief et les décors restent en place.

Glisse pour dessiner le cours d’eau. Les berges ajoutent une case autour de l’eau ; le relief et les décors restent en place.

Trace une zone pour répartir le décor. Les cases occupées, l’eau, la lave et le vide sont évités. Maximum : 250 éléments par geste.

Glisse sur la carte pour voir l’aperçu.
